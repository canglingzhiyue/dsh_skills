#### yangben-005 找 C2 用三类 API 全下断，别追业务逻辑
- 症状：不知道外联地址；静态搜不到域名；C2 已下线
- 判断：看到持久化（服务、注册表）、取址（InternetReadFile、recv）、解析三段调用 → 这是找 C2 的三段式，三类全下断基本不漏。
- 动作：WinINet 系（InternetOpen、CrackUrl、ReadFile）与 socket 系（connect、send、recv）一起挂；再 strings 看有无倒序或加密的结构化配置串。
- 无效则：全不下断时改为静态跟字符串解密调用点
- 失效条件：C2 只由外部配置递送、样本自身不含取址代码

#### yangben-006 C2 由解密函数产出时，取返回值而不是复现算法
- 症状：域名在静态串里找不到；解密函数很绕；只需要 IOC
- 判断：域名由运行时解密产出、静态零命中 → 在解密函数返回处取输出缓冲即可；样本价值在行为与 IOC，不在算法本身。
- 动作：对 XOR、查表、换序类解密，先断在函数返回读缓冲；只有要横向解历史样本或批量 IOC 时才把算法反写成脚本。
- 无效则：需要批量解历史密文时才反写解密脚本
- 失效条件：C2 分多段懒解密，单次返回缓冲不含完整地址
- 证据：weak ｜ 2源(52pj2) ｜ 2009–2016 ｜ 命中22

## 阶段：校验

#### yangben-008 判加密算法看常量表，不读轮函数
- 症状：不知道是什么算法；疑似 AES 或 DES；汇编里一堆位移
- 判断：S-Box 头部若干字节是已知标准值 → 直接定算法；再看有无 IV 区分 ECB 与 CBC；一加密一解密成对且共享 PRNG 核心 → 自研流密码。
- 动作：先扫标准常量表（SM4 与 AES 的 S-Box、DES 置换表、RC4 的 KSA 形状），命中即按标准算法处理，只核对 mode、padding、取位与大小写。
- 无效则：全不命中再按替换层与 PRNG 结构归类为自研算法
- 失效条件：算法常量表被换成自定义盒，标准指纹消失
- 证据：strong ｜ 3源(52pj3) ｜ 2015–2026 ｜ 命中4
