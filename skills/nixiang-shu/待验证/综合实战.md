- 症状：hook 了 API 检测全过；改机后仍被识别

#### zonghe-019 结论用三方对照，别只看修复版正常

- 判断：看到只有修复版正常 → 不能归因给改动，缺无注入与原版两组对照

#### zonghe-020 入口已 Bypass 不等于检测全过
- 症状：日志打出来了进程还是退；以为过了检测
- 判断：看到日志已输出但进程仍退出 → 检测在别处，别把半成品当结论
