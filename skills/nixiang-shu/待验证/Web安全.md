<a id="websec-011"></a>
#### websec-011 看改动后是否触发新请求判断层级
- 症状：UI 变了功能没通；界面显示会员但仍受限
- 判断：改动后触发了一次新请求 → 重新校验型，判定在下一次响应里；不触发而功能恢复 → 纯本地判定
- 动作：改动前后各抓一次包，比对请求数量与关键响应字段，据触发与否定性
- 无效则：只改展示层无效 → 改数据源 getter，不改副本字段
- 失效条件：功能下次冷启动重新拉配置并覆盖本地改动后，一次性的本地成功不再可持续
- 证据：single ｜ 2源(52pj2) ｜ 2016–2026 ｜ 命中5
- 锚点：561035,2121760

#### websec-014 URL 与 body 都对却 403 先查业务头
- 症状：403 但参数看着没错；照抄参数还是被拒　报错：`403 Forbidden`
- 判断：URL 与 body 与抓包一字不差仍 403 → 缺了自定义业务头（mauth/m-id/a-id 一类），缺一个就拒
- 动作：先把抓到的请求头整套复制重放，再逐个删除，定位哪几个是必需的
- 无效则：头部齐全仍 403 → 查 UA/Referer 与设备指纹是否参与校验
- 失效条件：服务端改为按签名覆盖头部字段后，逐个删头的实验会被签名校验掩盖，定位不到具体头
- 证据：single ｜ 2源(52pj2) ｜ 2020–2022 ｜ 命中13
- 锚点：1140773,1689022

<a id="websec-016"></a>
#### websec-016 分享试用类时长参数多半只校验格式
- 症状：分享能换时长；时长参数可以改；数量参数由客户端传
- 判断：时长/数量由客户端计算且服务端只验格式不验大小 → 喂一个格式合法但超大的值即可越权，不必动校验代码
- 动作：把时长/数量字段改成边界合法值（超长但格式对）重放，看是否被接受并到账
- 无效则：被拒 → 服务端有上限校验，回头按签名链与配额接口处理
- 失效条件：服务端改为下发时长并在服务端计配额后，客户端传的值不再生效
- 证据：single ｜ 2源(52pj2) ｜ 2022–2022 ｜ 命中3
- 锚点：1631768,1613856

<a id="websec-018"></a>
#### websec-018 JWT 先解前两段定算法，再定伪造还是重放
- 症状：抓到三段式 token；想自己造 token　报错：`exp`；`401 Unauthorized`
- 判断：解 header 得 alg=HS256 → 密钥在服务端，伪造无从下手，重放真 token 最省力；alg=none/RSA 另说
- 动作：解 header 与 payload，读 alg、exp、uid/jti，据 alg 定伪造还是重放
- 无效则：exp 短到几分钟 → 每次先登录拿新 token 再重放
- 失效条件：服务端校验 jti 一次性并绑 IP 后，重放真 token 同样失效
- 证据：single ｜ 1源(52pj1) ｜ 2022–2022 ｜ 命中9
- 锚点：1689022

<a id="websec-020"></a>
#### websec-020 伪随机 nonce 其实按公式可完全复现
- 症状：nonce 看起来是随机；自己造的 nonce 不对　报错：`验签失败`；`sign error`
- 判断：nonce = hash(固定常量 + 时间/elapsedRealtime) → 服务端只复算不验随机性，这种伪随机可完全离线复现
- 动作：在拼装处找 nonce 来源，按「常量+时间项」复现一个，再用真实请求验证同一公式
- 无效则：确认是真随机 → 只能重放或 hook，不做离线构造
- 失效条件：服务端记录已用 nonce 并做一次性校验后，复现出的值只能用一次
- 证据：single ｜ 2源(52pj2) ｜ 2021–2021 ｜ 命中24
- 锚点：1461832,1501673

<a id="websec-021"></a>
#### websec-021 服务端不校验新鲜度时本地造 nonce
- 症状：nonce 要不要复刻生成逻辑；回显 nonce 但不知校验强度
- 判断：服务端回显了 nonce 却接受任意时间戳 → 它不查新鲜度也未做一次性，本地随机生成即可过
- 动作：本地随机生成一个 nonce 发一次，能过就停止复刻生成逻辑
- 无效则：被拒 → 回到 websec-020 按公式复现
- 失效条件：服务端加 nonce 缓存表与时间窗口后，本地随机值开始被拒
- 证据：single ｜ 2源(52pj2) ｜ 2021–2022 ｜ 命中28
- 锚点：1501673,1702953

#### websec-024 前端混淆里按字段名与框架串搜，不按类名
- 症状：JS 全混淆找不到入口；类名全是 a/b/c
- 判断：类名可混淆但 header 名、builder.、login 这类框架特征串改不掉 → 从特征串命中的拼装处往上追整条链
- 动作：在已加载脚本里搜 header、encrypt、sign、builder.，落到拼装处再查调用方
- 无效则：命中过多 → 改搜唯一常量（域名、错误文案、固定盐）
- 失效条件：构建产物做了字符串数组化/加密后，特征串搜不到，须改按调用栈与运行时 hook 定位
- 证据：single ｜ 2源(52pj2) ｜ 2019–2020 ｜ 命中6
- 锚点：1330472,1013338

#### websec-025 补 JS 环境检测，否则本地复跑必报未定义
- 症状：扣下来的 JS 跑不起来；本地执行报 not defined　报错：`ReferenceError`；`not defined`
- 判断：执行即报 require/process 未定义 → 有环境检测分支，按检测点补桩而非删检测
- 动作：固定 require/process/document.domain/navigator 等探针返回值，补齐到与浏览器一致
- 无效则：仍报错 → 按调用栈定位新检测点
- 失效条件：检测改为对桩函数做 toString/原型链校验后，朴素补桩会被识破
- 证据：single ｜ 2源(52pj2) ｜ 2019–2026 ｜ 命中8
- 锚点：1013338,2134338

<a id="websec-026"></a>
#### websec-026 有状态加密必须常驻复用同一实例
- 症状：滑块/风控每次结果不同；同一入参加密不一致
- 判断：同一入参两次结果不同 → 加密有状态（计数器/种子内存），每次新建实例或新进程必错
- 动作：在同一页面上下文复用同一对象连续加密两次，比对输出是否只在预期字段上有差异
- 无效则：复用后仍不一致 → 状态来自服务端下发，先取种子再加密
- 失效条件：加密改为无状态纯函数后，新实例也能复现，常驻复用不再必要
- 证据：single ｜ 1源(52pj1) ｜ 2026–2026 ｜ 命中3
- 锚点：2134338

#### websec-029 GET 参数不进 POST 变量，注入点按方法判
- 症状：地址栏改参数没反应；参数明明传了却无效　报错：`200 但页面无变化`
- 判断：地址栏 GET 拼参提交毫无变化、而表单 POST 有响应 → 参数没进入同一个服务端变量，测错位置了
- 动作：拦下表单提交请求，在该请求的参数上做单引号/布尔真假的成对对照，看响应是否有差异
- 无效则：POST 也无差异 → 参数走 header 或路径段，换位置再测
- 失效条件：接口改用参数化查询或 WAF 做规范化拦截后，单引号对照不再产生可观测差异
- 证据：single ｜ 1源(52pj1) ｜ 2021–2021 ｜ 命中4
- 锚点：1522366
