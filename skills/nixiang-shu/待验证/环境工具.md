#### huanjing-017 权限或属主不对会被当成装了没反应
- 症状：框架装了但没反应；adb 侧读不到手机写的文件
- 判断：文件替换后没改权限 → app_process/.so 加载不上；跨身份写入 → 对端读不到，两边都不报错
- 动作：替换完立刻 chmod 777；中转统一放 /data/local/tmp 并 chmod -R 0777，先 mkdir/touch 预建
- 无效则：无写权限 → 走 Magisk 模块挂载，而不是硬替换系统文件
- 失效条件：出厂即启用 scoped storage 的设备上，0777 不足以保证对端可读
- 证据：single ｜ 1源(52pj1) ｜ 2020–2020 ｜ 命中11
- 锚点：1225793

#### huanjing-023 uiautomatorviewer 连不上改 adb 离线两件套
- 症状：uiautomatorviewer 连不上设备；控件树抓不出来
- 判断：8.0+ 上该工具依赖的旧 dump 通道断了 → 是工具废了不是设备坏了
- 动作：adb shell uiautomator dump 与 screencap 出两个文件，让工具离线加载
- 无效则：需要交互式控件树 → 换 uiautomator2 或 dumpsys 路线
- 失效条件：新版系统收紧 /sdcard 写入与应用可见性后，dump 落点与权限需重查
- 证据：single ｜ 1源(52pj1) ｜ 2019–2019 ｜ 命中15
- 锚点：1027006

#### huanjing-025 insmod 报 Exec format error 先查 vermagic
- 症状：内核模块加载报格式错误；以为是文件损坏　报错：`Exec format error`；`version magic`
- 判断：dmesg 里有 version magic 'X' should be 'Y' → vermagic 不匹配，文件没坏
- 动作：改 vermagic.h 与 utsrelease.h 的版本串，make clean 后重编
- 无效则：内核启模块签名 → 还要处理签名或换注入方案
- 失效条件：GKI 内核走模块 ABI 白名单与签名校验后，改 vermagic 不再生效
- 证据：single ｜ 1源(52pj1) ｜ 2024–2024 ｜ 命中4
- 锚点：1991042
