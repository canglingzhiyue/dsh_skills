# Camoufox 逆向环境 · 重建配方

这份文件的作用：**不备份任何大文件**，只靠下面的来源 + 版本 + 校验和，在任意 Windows 机器上把
整套环境重新拉起来。自制的小件（脚本、说明书）在 `scripts\` 和本目录里，直接复制即可。

体积对照：大件合计约 **2.2 GB**（引擎 1.89 GB + venv 271 MB + CPython 61 MB），全部可重下；
自制备份 **不到 100 KB**。

## 2. 一键重建

```powershell
pwsh -File scripts\restore.ps1                 # 默认装到 D:\AI_python\camoufox
pwsh -File scripts\restore.ps1 -Root E:\camoufox
pwsh -File scripts\restore.ps1 -SkipEngines    # 只建 venv + MCP，不下载引擎（约省 1 GB 流量）
```

脚本会：复制自制脚本与说明书 → 建目录联接 → 建 venv → 装 camoufox → clone MCP →
装官方引擎 → 装定制版引擎 → 预热 → 冒烟测试 → 打印 DSH 接入片段。

## 3. 手动步骤（脚本失败时照着做）

```powershell
$Root = 'D:\AI_python\camoufox'
New-Item -ItemType Directory -Force -Path $Root | Out-Null

# (1) 引擎缓存改落到工作区内：camoufox 用 platformdirs 硬取 %LOCALAPPDATA%，环境变量改不动，
#     所以用目录联接。**必须先建联接，再装引擎。**
New-Item -ItemType Directory -Force -Path "$Root\.engine\camoufox" | Out-Null
New-Item -ItemType Junction -Path "$env:LOCALAPPDATA\camoufox" -Target "$Root\.engine\camoufox"

# (2) 独立解释器 + venv
uv venv --python 3.12 --python-preference only-managed "$Root\.venv"
& "$Root\.venv\Scripts\python.exe" -m ensurepip --upgrade

# (3) 引擎封装
& "$Root\.venv\Scripts\python.exe" -m pip install -U "camoufox[geoip]"

# (4) MCP 源码
git clone https://github.com/WhiteNightShadow/camoufox-reverse-mcp.git "$Root\camoufox-reverse-mcp"
& "$Root\.venv\Scripts\python.exe" -m pip install -e "$Root\camoufox-reverse-mcp"

# (5) 官方引擎（绕开 GitHub API 未认证限流，直连 release CDN）
& "$Root\.venv\Scripts\python.exe" "$Root\bin\install-camoufox-browser.py" `
    v152.0.4-beta.30 camoufox-152.0.4-beta.30-win.x86_64.zip `
    ea52a02fb1cfb1813ef6a326bea03fb2b650c9774143d953a94a27bfc8f10072

# (6) 定制版引擎：从 release 下载 zip + SHA256SUMS + install-camoufox-reverse.py
& "$Root\.venv\Scripts\python.exe" "$Root\install-camoufox-reverse.py" `
    "$Root\camoufox-152.0.4-beta.30-win.x86_64.zip" `
    --sha256 d73704543a759a224371a8f3019f02ffa3a96fb446b25b7a856f5203b8e2153b

# (7) 预热（**必做**，否则第一次 launch_browser 会被插件下载的 stdout 污染搞挂）
& "$Root\.venv\Scripts\python.exe" "$Root\bin\warmup.py"

# (8) 验证
& "$Root\.venv\Scripts\python.exe" "$Root\bin\mcp_smoke_test.py" --browser
```

> 装定制版安装器前，缓存目录里必须已有官方引擎写下的 `.0.5_FLAG`（即第 5 步必须成功）。

## 4. DSH 接入片段（贴进 `$DSH_HOME\profiles\web\cordis.patch.yml`）

`cordis.patch.yml` 是**按 id 定位的 patch 列表**：`insert` 不带 `id` 表示"追加到顶层条目列表"，
所以新增插件就写这一条（路径按实际安装位置改）：

```yaml
- insert:
    - id: mcp-camoufox-reverse
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        serverName: camoufox
        transport: stdio
        command: 'D:\AI_python\camoufox\.venv\Scripts\python.exe'
        args:
          - '-m'
          - 'camoufox_reverse_mcp'
          - '--locale'
          - 'zh-CN'
        env:
          PYTHONUTF8: '1'
          PYTHONIOENCODING: 'utf-8'
        toolCallTimeoutMs: 120000
```

profile 是 `patchReload: live`，改完几秒内生效；验证方式（不会影响运行中的实例）：

```powershell
dsh --profile web --dump-config | Select-String 'mcp-camoufox-reverse' -Context 0,6
```

生效后工具以 `mcp__camoufox__*` 暴露（39 个），并且会有一个
`<venv>\Scripts\python.exe` 进程常驻。

## 6. 明确不备份的东西

| 东西 | 原因 | 重建方式 |
|---|---|---|
| 浏览器二进制（1.89 GB） | 有 release 来源 | 第 5、6 步现下 |
| `.venv` + CPython（332 MB） | 可从 PyPI 重装 | 第 2、3、4 步 |
| `states\*.json` | **含账号凭据**，与机器/站点绑定 | 用控制台菜单 `[2]/[3]` 重新登录一次 |
| `profiles\<站点>\` | 同上（持久 profile） | 同上 |
| `logs\`、`.pip-cache`、`.tmp` | 一次性产物 | 无需 |

> `states\` 与 `profiles\` 里是**可直接登录的凭据**：不要放进任何备份、云盘或仓库；
> 迁移到新机器后重新扫码登录一次即可。
